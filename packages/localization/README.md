# @rudralipi/localization

Framework-neutral localization contracts and complete English, German, Italian,
and Turkish editor catalogs for Rudralipi.

```sh
bun add @rudralipi/localization
```

See the [localization guide](https://github.com/mpoonuru/rudralipi/blob/main/docs/guides/localization.md).
