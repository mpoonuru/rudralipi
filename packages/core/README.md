# @rudralipi/core

Portable Rudralipi schemas, migrations, immutable commands, bounded history,
diagnostics, fixtures, and extension contracts.

```sh
bun add @rudralipi/core
```

See the [document model](https://github.com/mpoonuru/rudralipi/blob/main/docs/guides/document-model.md).
