# @rudralipi/rich-text-tiptap

Replaceable Tiptap adapter for Rudralipi's owned, portable rich-text AST.
Tiptap JSON is not the persisted document contract.

```sh
bun add @rudralipi/rich-text-tiptap
```

See the [extension guide](https://github.com/mpoonuru/rudralipi/blob/main/docs/guides/extensions.md).
