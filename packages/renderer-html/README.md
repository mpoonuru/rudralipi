# @rudralipi/renderer-html

Deterministic semantic HTML, preview CSS, print CSS, resource embedding, and
Content Security Policy output for compiled Rudralipi documents.

```sh
bun add @rudralipi/renderer-html
```

See the [PDF and print guide](https://github.com/mpoonuru/rudralipi/blob/main/docs/guides/pdf-and-print.md).
