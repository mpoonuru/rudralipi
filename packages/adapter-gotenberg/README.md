# @rudralipi/adapter-gotenberg

Defensive Gotenberg PDF transport for deterministic Rudralipi HTML. It enforces
endpoint policy, timeouts, payload limits, response limits, content type, and
PDF signature checks.

```sh
bun add @rudralipi/adapter-gotenberg
```

See the [PDF and print guide](https://github.com/mpoonuru/rudralipi/blob/main/docs/guides/pdf-and-print.md).
