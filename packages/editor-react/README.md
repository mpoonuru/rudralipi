# @rudralipi/editor-react

Controlled, accessible React editing surfaces for versioned Rudralipi
documents. The editor is advisory; adopting backends remain authoritative.

```sh
bun add @rudralipi/editor-react
```

Import `@rudralipi/editor-react/styles.css` once in the host application. See
the [integration guide](https://github.com/mpoonuru/rudralipi/blob/main/docs/guides/integration.md).
