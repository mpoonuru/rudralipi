# @rudralipi/compiler

Backend-authoritative validation and compilation for Rudralipi documents,
including controlled merge fields, conditions, private asset resolution,
limits, diagnostics, renderer IR, and canonical hashes.

```sh
bun add @rudralipi/compiler
```

See the [integration guide](https://github.com/mpoonuru/rudralipi/blob/main/docs/guides/integration.md).
