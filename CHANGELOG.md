# Changelog

All notable changes follow Semantic Versioning and are recorded here.

## 0.1.0-alpha.0

Initial pre-alpha vertical release:

- versioned document schema with controlled built-in blocks;
- migrations, immutable commands, history, and extension registry;
- deterministic compiler and HTML/print renderer;
- controlled merge fields, conditions, assets, fonts, and security limits;
- React editor and replaceable Tiptap rich-text adapter;
- English, German, Italian, and Turkish localization;
- browser save/reload playground and visual/accessibility regression suite;
- optional defensive Gotenberg PDF adapter;
- paged-document and long-table test fixtures.

The schema, extension API, and renderer contracts remain unstable until a
future stable release.
